## 常见问题

**海外云服务器真的不用备案吗？**

是。ICP备案只针对接入中国大陆机房的网站域名，机房在香港或任何境外节点都免备案。但要注意，免备案不等于免监管，站点内容仍需符合相关法律法规。

**香港节点访问大陆快吗？**

香港物理距离近，延迟通常在几十毫秒量级，大陆访问体验普遍好于美国节点，普通建站完全够用。实际速度还受回程线路影响，这也是华纳云这类商家反复强调CN2直连的原因——对大陆访问质量有极端要求的，可以往主打直连线路的商家方向比较。

**可以用支付宝付款吗？**

阿里云可以，支付宝、微信都支持，也不需要外币卡。国际平台里DigitalOcean明确不支持支付宝，注册和付费流程对国内用户都不算友好。

**288元/年的轻量，第二年续费多少钱？**

续费按官网当时的标准价计算，不再享受新人活动价，具体金额以到期前订单页显示为准。这就是为什么预算确定的话建议一次买满一年——把低价周期用足。
